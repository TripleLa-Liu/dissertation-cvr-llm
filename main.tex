\chapter*{Abstract}
\thispagestyle{fancy}
\addcontentsline{toc}{chapter}{Abstract}

Conversion Rate (CVR) prediction — estimating the probability that a user will complete a purchase after clicking an advertisement — is a critical task in commercial recommender systems. Two persistent challenges limit the performance of existing models: first, the \textit{delayed feedback problem}, whereby conversions occur long after the initial click, causing training labels to be temporarily mislabelled as negative (false negatives); second, the reliance on \textit{ID-based embeddings}, which carry no semantic understanding of users or items, and perform poorly for users with sparse interaction histories.

This dissertation proposes a unified architecture that addresses both limitations simultaneously. A pre-trained Large Language Model (LLM) encoder replaces conventional ID embeddings by generating semantic representations from item and user textual descriptions. These representations are integrated into a Dynamic Graph Sequential Recommendation (DGSR) framework, which models cross-user collaborative signals over time using long-term and short-term preference attention. A delayed feedback correction layer, drawing from the DEFER and FSIW approaches, is applied to the training objective to reduce the disruptive effect of false-negative labels.

Empirical evaluation on the Ali-CCP dataset addresses three research questions: whether LLM embeddings improve CVR prediction performance over ID-based baselines (RQ1); whether LLM semantic features help mitigate delayed feedback bias (RQ2); and what the computational trade-off of this integration is (RQ3). Ablation experiments isolate the contribution of each architectural component.

\vspace{1cm}
\textbf{Keywords:} Conversion Rate Prediction, Delayed Feedback, Large Language Models, Dynamic Graph Neural Networks, Recommender Systems, False Negative Correction
